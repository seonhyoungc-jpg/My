# 키워드 맵 양식 (Keyword Map)

Agent 2(SEO)가 작성. 섹션별 키워드 배치 계획.

```markdown
## 핵심 키워드
<메인 키워드 1개>

## 연관 키워드
| 키워드 | 유형 | 우선순위 |
|--------|------|----------|
| <A> | 연관 | 상 |
| <B> | 롱테일 | 중 |
| <C> | 연관 | 중 |

## 섹션별 배치
| 섹션 | 주요 키워드 | 보조 키워드 |
|------|-------------|-------------|
| 제목 | 핵심 | - |
| 도입 | 핵심 | A |
| 섹션1 | A | B |
| 섹션2 | B | C |
| 섹션3 | C | 핵심 |
| 마무리 | 핵심 | - |

## 밀도 목표
- 핵심 키워드: 5~10회 (밀도 1~2%)
- 스터핑 금지: 한 문단 내 동일 키워드 2회 이하
```
