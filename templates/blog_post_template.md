# 블로그 원고 템플릿 (Writer 골격)

Agent 3(작성)이 사용하는 기본 골격. `<...>` 부분을 채운다.

```markdown
# <제목 — 핵심 키워드 앞쪽, 32자 내외>

<도입 문단: 공감/질문/문제 제기로 후킹. 첫 100자에 핵심 키워드 + 결론 요약(메타 대응). 2~4문장.>

[이미지: 대표 썸네일 — <설명>]

## <섹션1 소제목>
<본문 3~6문장. 핵심 포인트 + 구체 정보. 필요 시 아래처럼 리스트.>
- <포인트1>
- <포인트2>

[이미지: <섹션1 관련 이미지 설명>]

## <섹션2 소제목>
<본문...>

| 항목 | 내용 |
|------|------|
| <비교1> | <...> |
| <비교2> | <...> |

[이미지: <섹션2 관련 이미지 설명>]

## <섹션3 소제목>
<본문...>

## 마무리
<핵심 요약 2~3문장 + 부드러운 CTA(댓글/이웃추가/다음 글 안내 등)>

---
**태그:** #<핵심> #<연관1> #<연관2> #<연관3> #<연관4> #<연관5> #<롱테일1> #<롱테일2>

> 출처: <통계/인용 링크>
```

## 체크
- 이미지 마커 3개 이상
- 소제목 3~5개
- 태그 8~10개
- 분량 1,500자 이상
