# 스케줄링 & 콘텐츠 보드 운영 가이드

주 3회 발행을 **Google Sheets(또는 콘텐츠 갤러리)** 로 관리하고, 예약 발행/자동화하는 방법.

---

## 1. Google Sheets 콘텐츠 보드 세팅

1. `templates/content_board.csv` 를 Google Sheets로 **가져오기(Import)**
2. 컬럼 구성:

| 컬럼 | 설명 |
|------|------|
| ID | 콘텐츠 고유번호 |
| 발행예정일 | YYYY-MM-DD |
| 요일 | 월/수/금 (주3일) |
| 콘텐츠유형 | 정보성/후기/리스트/비교/영상 |
| 주제 | 글 주제 |
| 핵심키워드 | 메인 키워드 |
| Status | 아이디어→기획→작성중→검수→미디어→조립완료→예약발행→발행됨→추적중 |
| 담당단계 | 현재 진행 중인 에이전트(①~⑧) |
| 제목 | 확정 제목 |
| 영상포함 | Y/N |
| 발행URL | 발행 후 링크 |
| 발행일 | 실제 발행일 |
| 노출키워드순위 | 검색 노출 순위(추적) |
| 조회수_D3 / 조회수_D7 | 발행 후 조회수 |
| 비고 | 메모 |

3. **조건부 서식**으로 Status별 색상 지정 (예: 발행됨=초록, 검수=노랑) → 갤러리처럼 한눈에 파악

### 자동 연동(선택)
- MCP **Google Sheets/Supabase** 연동 시 Claude가 보드를 직접 읽고/업데이트 가능
- 본 저장소에는 Supabase MCP도 연결되어 있어, 원하면 콘텐츠 보드를 DB 테이블로 운영 가능

---

## 2. 콘텐츠 갤러리 (대안)
Google Sheets 대신 시각적 카드 형태로 운영하려면:
- Notion 데이터베이스(갤러리 뷰) — 썸네일 카드로 콘텐츠 관리 (Notion MCP 연동 가능)
- 각 카드 = 하나의 콘텐츠, 속성 = 위 컬럼과 동일

---

## 3. 주 3일 스케줄 규칙
- 발행 요일: **월/수/금** (기본), 시간은 타깃 활동 시간대
- **버퍼 3편** 유지 (콘텐츠 재고 부족 시 발행 리듬 붕괴 방지)
- 리드타임: 발행 3일 전 기획 시작 (`workflow/content_calendar.md`)

---

## 4. 예약 발행
### 수동(권장·안전)
- 네이버 블로그 에디터 → **예약 발행** → 날짜/시간 지정
- 등록 후 보드 `Status = 예약발행`

### 자동화 옵션
- 네이버는 공식 발행 API가 제한적이므로 완전 무인 자동 발행은 정책 위반 위험이 있음.
- 실무 권장: **원고/이미지/영상까지 자동 생성 → 사람이 최종 확인 후 예약 발행** (반자동)
- 리마인더 자동화: 발행일 전날 알림 (예: Slack MCP로 "내일 발행 예정 3편" 알림 발송)

---

## 5. 리마인더 & 리포트 자동화 (이 환경에서 가능)
- **발행 리마인더**: D-1에 Slack으로 "예약 발행 대상" 알림
- **추적 리포트**: 발행 D+3/D+7에 검색 노출·조회수 리포트 자동 작성 (Agent 8)
- 정기 실행이 필요하면 스케줄 트리거(Routine)로 매주 월요일 캘린더 점검 자동화 가능
