# 양고기 도메인 가이드 (고메365)

Agent 1(기획)·Agent 3(작성)이 양고기 글을 쓸 때 참조하는 기본 지식과 키워드 전략.

> ⚠️ 아래는 일반적으로 알려진 내용입니다. **고메365의 실제 상품 정보는 `brand_assets.md`에 사장님이 채워주신 값을 우선**합니다. 산지·등급·가격·중량은 추측해서 쓰지 않습니다.

---

## 1. 왜 양고기로 시작하는가 (전략)

| | 소·돼지고기 | 양고기 |
|---|---|---|
| 검색량 | 많음 | 적음 |
| 경쟁 | 매우 높음 (대형 블로그·쇼핑광고) | **낮음** |
| 취급 업체 | 수천 곳 | **소수** |
| 신규 블로그 노출 | 거의 불가 | **가능** |
| 구매 전환 | 비교 후 이탈 많음 | **대체재 적어 높음** |

→ 양고기로 **주제 전문성(C-Rank)을 선점**한 뒤 소·돼지로 확장.

## 2. 기본 지식

### 연령 구분 (누린내의 핵심)
| 구분 | 연령 | 특징 |
|------|------|------|
| **램 (Lamb)** | 생후 12개월 미만 | 누린내 약함, 육질 부드러움 — **입문자용** |
| **호겟 (Hogget)** | 12~24개월 | 중간 |
| **머튼 (Mutton)** | 24개월 이상 | 누린내 강함, 풍미 진함 |

> **램을 머튼으로, 머튼을 램으로 표기하면 거짓 표시**입니다. 반드시 정확히.

### 누린내의 원인
- 양고기 특유의 향은 **지방에 포함된 성분**에서 주로 나옵니다
- 성체(머튼)일수록 강해집니다
- → 실무 대응: **램 선택 / 겉지방 손질 / 허브·향신료 활용**

### 주요 부위
| 부위 | 영문 | 특징 | 조리 |
|------|------|------|------|
| 램찹 | Rib chop | 갈비 부분, 뼈 붙음 | 구이 (가장 대중적) |
| 프렌치랙 | French rack | 갈비 통째, 비주얼 좋음 | 오븐 구이 |
| 숄더랙 | Shoulder rack | 어깨, 가격 합리적 | 구이·스튜 |
| 다리살 | Leg | 지방 적고 담백 | 구이·수비드 |
| 등심 | Loin | 부드러움 | 스테이크 |

### 주요 산지
한국 유통 양고기는 **호주·뉴질랜드산**이 대부분입니다.
→ 고메365 실제 산지는 `brand_assets.md` 확인 후 기재

### 조리 기본
- 궁합 허브: 로즈마리, 민트, 타임, 커민
- 굽기: 실온에 잠시 두었다가 센 불에 겉면 → 중불
- 과하게 익히면 질겨짐

## 3. 키워드 전략

### 핵심 키워드 (경쟁 낮음, 우선 공략)
- 양고기 누린내
- 양고기 부위
- 양갈비 굽는 법
- 램찹 굽는 법
- 양고기 손질
- 양고기 보관 / 해동
- 양고기 처음

### 중간 키워드
- 양고기 추천 / 양갈비 추천
- 프렌치랙 / 숄더랙
- 양고기 산지 / 호주 뉴질랜드 양고기
- 양고기 소스 / 밑간

### 피할 키워드 (경쟁 과다, 초기엔 비효율)
- 양고기 맛집 (지역 블로그 장악)
- 한우 / 소고기 선물세트
- 삼겹살

### 주제 클러스터 설계
```
[허브] 양고기 입문 — 누린내·부위 고르기
   ├─ 양갈비 굽는 법 (프라이팬)
   ├─ 양고기 손질법 (겉지방 정리)
   ├─ 양고기 보관·해동법
   ├─ 산지별 차이 (호주 vs 뉴질랜드)
   ├─ 부위별 용도 (램찹/숄더랙/다리살)
   └─ 양고기 밑간·소스
```
서로 내부 링크로 연결 → 체류시간·주제 전문성 강화

- **효능 금지**: `food_ad_compliance.md` 치환 사전 준수. 양고기에 "보양", "면역력" 붙이지 않음
