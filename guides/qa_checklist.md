# QA 체크리스트 — 중간 테스트 (Quality Gate)

Agent 4(편집·검수)가 `3_draft.md`를 채점하는 기준. **Critical은 전부 통과**, **Recommended는 80% 이상** 이어야 PASS.

---

## 🔴 Critical (필수 — 하나라도 실패 시 FAIL)

- [ ] **C1. 제목**에 핵심 키워드 포함 & 32자 내외
- [ ] **C2. 금지 표현 없음** (`prohibited_expressions.md` 대조)
- [ ] **C3. 허위·과장·근거 없는 단정 없음** (통계/효능은 출처 표기)
- [ ] **C4. 저작권 안전** (타 블로그 복붙 X, 이미지 저작권 문제 X)
- [ ] **C5. 주제 일치** — 본문이 제목/개요의 검색 의도를 충족
- [ ] **C6. 최소 분량** 1,500자 이상
- [ ] **C7. 이미지 마커 3개 이상**
- [ ] **C8. 개인정보/민감정보 노출 없음**

## 🟡 Recommended (권장 — 80% 이상 통과)

- [ ] R1. 첫 문단에 핵심 키워드 + 결론 요약 (메타 대응)
- [ ] R2. 핵심 키워드 본문 5~10회, 밀도 1~2% (스터핑 X)
- [ ] R3. 소제목(H2)로 섹션 구분, 3~5섹션
- [ ] R4. 문단당 3~6문장, 문장 60자 이내 지향
- [ ] R5. 리스트/표 등 가독성 장치 1개 이상
- [ ] R6. 태그 8~10개, 주제 관련성 있음
- [ ] R7. 마무리에 요약 + CTA
- [ ] R8. 맞춤법/띄어쓰기 오류 없음
- [ ] R9. 독창적 정보/경험 포함 (D.I.A. 대응)
- [ ] R10. 톤이 스타일 가이드와 일치

---

## 채점 방식
1. 각 항목 ✅/❌ 표시 + 근거 한 줄
2. Critical 하나라도 ❌ → **즉시 FAIL** + 수정 지시
3. Critical 전부 ✅ & Recommended ≥ 80% → **PASS**
4. 애매하면 가이드 문서 기준을 우선

## FAIL 처리
- `4_qa_report.md`에 **구체적 수정 지시**(무엇을, 어떻게) 작성
- Agent 3(작성)으로 되돌려 재작업 → 다시 QA (최대 2~3회 반복)
