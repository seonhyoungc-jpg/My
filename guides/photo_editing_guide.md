# 사진 보정 가이드 (포토샵 / 무료 대안)

블로그용 고기 사진 보정. **촬영 가이드는 `photo_guide.md` 참고.**

---

## 0. 원칙 — 식품 사진은 보정 수위에 선이 있습니다

| ✅ 해도 되는 것 | ❌ 하면 안 되는 것 |
|---|---|
| 어둡게 나온 것 밝히기 | 고기를 실제보다 붉게 |
| 기울어진 수평 맞추기 | 지방을 하얗게 지우기 |
| 누런 색감(형광등) 중립으로 | 크기·양을 부풀리기 |
| 배경 얼룩·부스러기 지우기 | 없는 마블링 그려 넣기 |
| 자르기·구도 정리 | 다른 고기 사진 합성 |

**기준**: *실제로 받아보신 손님이 "사진이랑 같네"라고 하면 OK, "이게 그거야?"면 선을 넘은 것.*

> 과장된 식품 이미지는 부당광고로 문제될 수 있습니다 (`food_ad_compliance.md`).

---

## 1. 포토샵 — 순서대로 5단계

순서가 중요합니다. **자르기 → 색온도 → 밝기 → 채도 → 선명도** 순으로 하세요.

### ① 자르기 + 수평 (C)
- `C` 키 → 모서리 드래그
- **수평 기울어졌으면**: 자르기 상태에서 모서리 **바깥쪽**에 커서를 두면 회전 커서가 뜹니다
- 블로그는 **가로형 4:3 또는 3:2**가 무난합니다
- 접시 가장자리나 배경 잡동사니는 여기서 잘라냅니다

### ② 색온도 (화이트밸런스)
형광등 아래서 찍어 **누렇게 뜬 사진**을 되돌리는 단계입니다.

- `필터 → Camera Raw 필터` (Ctrl/⌘ + Shift + A)
- **색온도(Temperature)**: 누렇다 → 왼쪽(파랑) / 푸르다 → 오른쪽(노랑)
- **색조(Tint)**: 초록빛 돌면 오른쪽(마젠타)
- 흰 접시가 **진짜 흰색으로 보일 때까지**가 기준점입니다

### ③ 밝기·대비
같은 Camera Raw 창에서 이어서 합니다.

- **노출**: 전체 밝기. 살짝 밝게 (+0.2 ~ +0.5)
- **그림자**: 올리면 어두운 부분이 살아남 (+20 ~ +40)
- **밝은 영역**: 내리면 번들거리는 기름 반사가 죽음 (-10 ~ -30)
- **대비**: 살짝만 (+5 ~ +15)

> 포토샵만 쓰신다면 `이미지 → 조정 → 곡선`(Ctrl/⌘+M)으로 S자 커브를 살짝 그려도 됩니다.

### ④ 채도 — 조심해서
**여기가 과하면 가짜 사진이 됩니다.**

- **생동감(Vibrance)**: +10 ~ +20 ← 이것만 쓰세요
- **채도(Saturation)**: **건드리지 마세요**. 고기가 형광 빨강이 됩니다
- 생동감은 이미 진한 색은 덜 올리고 흐린 색만 올려서 안전합니다

### ⑤ 선명도
- `필터 → 선명 효과 → 언샵 마스크`
- 양 **80~120%**, 반경 **1.0px**, threshold **2~3**
- 과하면 가장자리가 지글거립니다. **100% 확대해서 확인**하세요

### 추가 — 얼룩 지우기 (J)
- **스팟 복구 브러시** (`J`) → 지울 부분 클릭
- 접시에 튄 기름방울, 배경 부스러기 정도만
- **고기 자체는 건드리지 마세요**

## 2. 저장 — 블로그용

- `파일 → 내보내기 → 웹용으로 저장(레거시)` 또는 `빠른 내보내기`
- **형식**: JPG, 품질 **70~80**
- **가로 1000px 내외**로 리사이즈 (너무 크면 로딩이 느려 이탈)
- **파일명을 SEO 규칙대로** 바꾸기 ← 중요
  - `lamb-smell-01.jpg` (각 글의 `5_image_prompts.md`에 지정돼 있음)
  - `IMG_1234.jpg` 그대로 올리면 검색에 아무 도움이 안 됩니다

## 3. 포토샵 없이 — 더 빠른 대안

솔직히 **주 3회 블로그에는 포토샵이 과합니다.** 아래가 더 현실적입니다.

### 폰 기본 편집 (가장 빠름, 1분)
사진 열기 → **편집** → 자동 보정 한 번 누르고, 아래만 손봅니다.
- **밝게** 살짝 ↑ / **그림자** ↑ / **따뜻함** 조절(누런 기 제거) / **선명도** 살짝 ↑
- **채도는 손대지 않기**

### Snapseed (무료 앱, 추천)
- `도구 → 기본 보정`에서 밝기·대비·분위기·그림자
- `도구 → 흰색 균형`으로 색온도
- `도구 → 부분 보정`으로 고기만 선택해 밝히기 ← 포토샵급 기능인데 무료

### Lightroom 모바일 (무료 버전으로 충분)
- 포토샵의 Camera Raw와 동일한 조절값
- 한 사진 보정 후 **설정 복사 → 나머지 사진에 붙여넣기** = 톤 통일
- **주 3회 운영에는 이게 제일 효율적입니다**

---

## 4. 실무 추천 흐름

```
촬영 (photo_guide.md)
   ↓
Lightroom 모바일에서 1장 보정
   ↓
설정 복사 → 나머지 사진에 일괄 적용   ← 톤이 통일됨
   ↓
파일명을 SEO 규칙대로 변경
   ↓
네이버 업로드
```

**사진 4장 기준 5분이면 끝납니다.** 포토샵으로 하면 30분 걸립니다.

## 5. 블로그 전체 톤 통일

글마다 사진 톤이 제각각이면 블로그가 산만해 보입니다.
**첫 글 보정값을 저장해두고 계속 같은 값을 쓰세요.**

고메365 권장 톤:
- 밝고 깨끗하게 (어둡고 무거운 톤 X)
- 따뜻한 쪽으로 아주 살짝 (식욕)
- 채도는 낮게 유지 — **고기는 과채도가 제일 티납니다**
