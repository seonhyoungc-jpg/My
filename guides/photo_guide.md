# 고기 사진 촬영 가이드 (스마트폰)

블로그용 고기 사진을 폰으로 찍는 법. **장비 필요 없습니다.** 조명과 각도만 지키면 됩니다.

> 식품 판매자는 **실사가 원칙**입니다. AI 생성 이미지는 실제 상품으로 오인될 소지가 있고,
> 네이버도 직접 촬영한 이미지를 더 높게 평가합니다. (`food_ad_compliance.md` 참고)

---

## 1. 조명 — 이것만 지켜도 80%

| | 하세요 | 하지 마세요 |
|---|---|---|
| 광원 | **창가 자연광** | 형광등·전구 아래 |
| 방향 | **옆에서 들어오는 빛** (측광) | 정면 플래시 |
| 시간 | 낮, 흐린 날도 좋음 | 밤 (색이 누렇게 뜸) |

- 창문을 **왼쪽이나 오른쪽**에 두고 찍으면 고기 질감과 입체감이 살아납니다
- **플래시는 절대 금지** — 기름이 번들거리고 색이 날아갑니다
- 주방이 어두우면 **창가 식탁으로 옮겨서** 찍으세요

## 2. 배경 — 단순할수록 좋습니다

- **흰 접시** 또는 **나무 도마**
- 배경은 단색 (흰 천, 원목 테이블, 무지 종이)
- 뒤에 **그릇·행주·조미료통이 보이지 않게** 치우기
- 고기가 화면의 **70% 이상** 차지하게

## 3. 각도 — 찍을 대상에 따라 다릅니다

| 찍는 것 | 각도 | 이유 |
|---|---|---|
| 생고기 / 지방 상태 | **위에서 45도** | 지방층과 살코기가 함께 보임 |
| 지방 두께 비교 | **옆에서 수평** | 두께가 가장 잘 드러남 |
| 구운 고기 | **위에서 45도** | 겉면 크러스트가 보임 |
| **썬 단면** | **정면 수평** | 속 익힘 정도가 정확히 보임 |
| 손질 과정 | 위에서 수직(탑뷰) | 손과 칼이 같이 들어감 |

## 4. 폰 설정

1. **그리드 켜기** (설정 → 카메라 → 격자)
2. 찍을 부분을 **한 번 탭** → 초점 + 노출 맞춤
3. 탭한 뒤 **위아래로 쓸어서 밝기 조절** — 살짝 밝게가 좋습니다
4. **줌 쓰지 말고** 몸을 가까이

## 5. 타이밍

- 구운 고기는 **레스팅 직후, 김이 올라올 때**가 가장 먹음직스럽습니다
- 단면 사진은 **썰자마자** — 시간이 지나면 육즙이 마르고 색이 변합니다
- 그래서 **접시·배경을 미리 세팅해두고** 구우세요

## 6. 한 번에 여러 컷

같은 장면을 **각도만 바꿔 5~6장** 찍어두세요. 나중에 고르는 게 빠릅니다.
한 번 조리하실 때 아래 전부 찍으면 글 두세 편 분량이 나옵니다.

## 글별 촬영 리스트

### 1번 글 — 양고기 누린내 (11/23)
| 컷 | 내용 | 각도 | 중요도 |
|---|---|---|---|
| 썸네일 | 호주산 램 생고기 | 45도 | ★★ |
| **필수** | **겉지방과 살코기 비교** | **옆에서 수평** | ★★★ |
| **필수** | **3mm 손질 전 / 후** (2컷, 같은 각도) | 탑뷰 | ★★★ |
| 마무리 | 구운 램찹 | 45도 | ★★ |

### 2번 글 — 양갈비 굽는 법 (11/25)
| 컷 | 내용 | 각도 | 중요도 |
|---|---|---|---|
| 썸네일 | 팬에서 구워지는 양갈비 | 45도 | ★★ |
| **필수** | **지방 면을 세워 굽는 모습** | 옆에서 수평 | ★★★ |
| 굽는 중 | 기름 끼얹기 | 45도 | ★★ |
| **필수** | **레스팅 후 썬 단면** | **정면 수평** | ★★★ |
| 영상 | 전 과정 40초 | 고정 45도 | ★★ |

> 💡 **한 번에 끝내는 법**: 양갈비를 한 번 구우시면서 **영상을 처음부터 끝까지 고정으로 찍어두세요.**
> 그 영상에서 스틸을 뽑으면 2번 글 사진 4장이 다 나옵니다. 손질할 때 2컷만 추가로 찍으면 1번 글도 해결됩니다.

## 자주 하는 실수

| 실수 | 결과 |
|---|---|
| 형광등 아래에서 촬영 | 고기가 창백하거나 누렇게 뜸 |
| 플래시 사용 | 번들거리고 그림자가 딱딱함 |
| 배경 안 치움 | 생활감이 그대로 노출 |
| 너무 멀리서 | 고기가 작게 나와 전달 안 됨 |
| 단면을 45도로 | 익힘 정도가 안 보임 → **정면으로** |
| 식은 뒤 촬영 | 윤기와 김이 없어 맛없어 보임 |
