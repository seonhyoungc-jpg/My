# 자동화 범위 — 무엇이 자동이고 무엇이 수동인가

고메365 (네이버 스마트스토어, 양고기) 블로그 운영 기준.

---

## ❌ 자동화할 수 없는 것 (하면 안 되는 것)

**네이버 블로그는 공식 발행 API가 없습니다.**

- 과거 네이버 블로그 글쓰기 API는 일반 사용자에게 제공되지 않습니다
- 셀레니움/매크로 등 **브라우저 자동화로 자동 발행하면 네이버 운영정책 위반** 소지가 있습니다
- 적발 시 글 삭제, 검색 노출 제외, **계정 제재**까지 갈 수 있습니다
- 사업 계정으로 이런 리스크를 지는 건 명백히 손해입니다

→ **발행 버튼은 사람이 누릅니다.** 이건 타협하지 않습니다.

## ✅ 자동화되는 것 (전체의 90%)

| 단계 | 자동화 | 사람이 할 일 |
|------|--------|--------------|
| 주제 발굴 | ✅ 키워드·경쟁 분석 | 승인 |
| SEO 설계 | ✅ 제목·키워드맵·태그 | — |
| 본문 초안 | ✅ 구조·흐름·문장 | **실제 경험·수치 주입** |
| 검수(QA) | ✅ 식품광고 규제·금지표현·분량 자동 체크 | — |
| 이미지 | ✅ 프롬프트 설계 | **실사 촬영 권장** |
| 조립 | ✅ 발행용 완성본 | — |
| 발행 | ❌ | **붙여넣기 + 예약발행** |
| 노출 추적 | ⚠️ 부분 | 통계 수치 입력 |

**실제 작업 시간: 글당 10~20분** (사진 넣고 발행 누르는 시간)

## 왜 "원고 100% 자동"도 안 되는가

네이버는 2025년부터 **LLM으로 문서를 평가**합니다. 경험 없는 일반론은 자동 생성 저품질로 걸러집니다.
AI가 쓴 게 문제가 아니라, **내용이 뻔한 게** 문제입니다.

그래서 초안에 `[사장님 입력]` 마커를 넣습니다. QA 단계에서 이 마커가 남아 있으면 **발행 단계로 넘기지 않습니다.**

### 사장님만 넣을 수 있는 것 (= 노출의 핵심)
- 직접 찍은 사진 (입고 상태, 손질 과정, 구운 결과)
- 실제 거래 산지·입고 주기·숙성 일수
- 실제 단가대
- 손님들이 실제로 물어본 질문
- 직접 구워보고 실패한 경험 ← **가장 강력함**

이 재료를 한 번 모아두면(`guides/brand_assets.md`) 이후 글에 재사용됩니다.

## 주간 운영 흐름 (주 3일 발행)

```
[월 오전] 이번 주 3편 주제 승인          ← 5분
    ↓
[자동]   ①기획 → ②SEO → ③작성 → ④QA     ← Claude
    ↓
[사장님] 각 글에 사진·실제정보 주입        ← 글당 10분
    ↓
[자동]   ④QA 재검수 → ⑥조립              ← Claude
    ↓
[사장님] 네이버에 붙여넣고 예약발행        ← 글당 5분
    ↓
[자동]   ⑧ D+3/D+7 노출 추적 → 다음 주제 반영
```

**주당 사장님 소요: 약 1시간**

## 발행 자동화를 더 당기는 안전한 방법

자동 발행은 못 하지만, 주변을 자동화해서 체감 수고를 줄일 수 있습니다.

1. **네이버 블로그 예약 발행 기능 활용** — 한 번에 3편을 미리 등록해두면 주중에 손 안 댐
2. **발행 리마인더** — 발행 전날 알림 (Slack 등)
3. **콘텐츠 보드 자동 갱신** — Google Sheets 상태 동기화
4. **주간 성과 리포트 자동 생성**

→ 설정은 `guides/scheduling_guide.md` 참고
