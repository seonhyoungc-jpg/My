# 콘텐츠 캘린더 & 발행 스케줄 (주 3일 운영)

네이버 블로그 **주 3회 발행**을 기준으로 한 콘텐츠 파이프라인 운영 캘린더.

## 1. 기본 발행 리듬 (주 3일)

권장 발행 요일/시간 (타깃 활동 시간대 기준, 필요 시 조정):

| 요일 | 발행 시간 | 콘텐츠 유형(예시) |
|------|-----------|-------------------|
| **월** | 오전 8:00 | 정보성/가이드 글 |
| **수** | 저녁 8:00 | 후기/경험 글 |
| **금** | 저녁 8:00 | 리스트/비교 + **영상 포함** 글 |

> C-Rank는 **꾸준한 발행 주기**를 신뢰도로 반영합니다. 주 3회를 규칙적으로 지키는 것이 핵심.

## 2. 콘텐츠 상태(Status) 흐름

각 콘텐츠는 아래 상태를 거칩니다. (Google Sheets `Status` 컬럼과 동일)

```
아이디어 → 기획 → 작성중 → 검수(QA) → 이미지/영상 → 조립완료 → 예약발행 → 발행됨 → 추적중
 Idea     Plan   Writing   Review    Media       Assembled  Scheduled  Published  Tracking
```

## 3. 리드타임 (발행 3일 전 준비 완료)

주 3회를 안정적으로 운영하려면 **최소 3일치 재고(버퍼)** 를 유지합니다.

| D-day | 작업 |
|-------|------|
| D-3 | ① 기획·리서치 → ② SEO |
| D-2 | ③ 작성 → ④ QA(중간 테스트) |
| D-1 | ⑤ 이미지 / ⑦ 영상 → ⑥ 조립 → **예약 발행 등록** |
| D-0 | 발행 → ⑧ 추적 시작 |
| D+3, D+7 | 검색 노출/통계 추적 리포트 |

## 4. 주간 운영 루틴

- **월요일**: 이번 주 3편 상태 점검 + 다음 주 주제 3개 확정 (아이디어→기획)
- **수요일**: 재고 버퍼 확인 (부족하면 기획 추가)
- **금요일**: 발행 완료분 추적 리포트 확인 + 다음 주 캘린더 확정
