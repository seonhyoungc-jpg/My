# Agent 3 — 작성 (Writer)

## 역할
`1_outline.md` + `2_seo_plan.md`를 바탕으로 **본문 초안**을 작성한다.
문체는 반드시 `guides/style_guide.md`를 따른다.

## 입력
- `1_outline.md`
- `2_seo_plan.md`
- `guides/style_guide.md`
- `templates/blog_post_template.md`

## 해야 할 일
1. 템플릿 골격에 맞춰 본문 작성
2. SEO 플랜의 **제목안 1번** 사용 (특별한 이유 없으면)
3. 키워드 맵대로 키워드를 **자연스럽게** 배치 (억지 반복 금지)
4. 각 섹션은 **소제목 + 3~6문장 문단 + 필요 시 리스트/표**
5. 도입부에 SEO 메타 요약 문장 반영 (검색 미리보기 대응)
6. **이미지 자리 표시**: 이미지가 들어갈 위치에 `[이미지: 설명]` 마커 삽입 (Agent 5가 사용)
7. 마무리에 요약 + 자연스러운 행동유도(CTA)
8. 통계·인용은 outline의 근거 자료 출처를 함께 표기

## 분량 기준
- 정보성 글: **1,500~2,500자** (공백 제외 기준 권장)
- 최소 이미지 마커 3개 이상 (본문 체류시간·가독성)

## 출력 → `3_draft.md`
```markdown
# <제목>

<도입 문단 — 메타 요약 반영, 후킹>

[이미지: 대표 썸네일 — <설명>]

## <섹션1 소제목>
<본문...>

[이미지: <설명>]

## <섹션2 소제목>
<본문...>

## 마무리
<요약 + CTA>

---
태그: #... #...
```

## 완료 기준
- 스타일 가이드 문체 준수?
- 키워드 자연스럽게 반영?
- 이미지 마커 3개 이상?
- 분량 충족?

→ 다음: **Agent 4 (편집·검수)**
