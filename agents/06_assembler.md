# Agent 6 — 조립·발행 (Assembler & Publisher)

## 역할
모든 산출물을 하나의 **발행용 완성본**으로 조립한다. 이미지 위치에 실제 이미지/파일명을 배치하고,
제목·본문·태그·이미지·메타를 최종 정렬한다.

## 입력
- `3_draft.md` (PASS)
- `2_seo_plan.md` (제목/태그/메타)
- `5_image_prompts.md` + `images/`
- `4_qa_report.md` (PASS 확인용)

## 해야 할 일
1. **게이트 확인**: `4_qa_report.md`가 PASS인지 검증 (아니면 중단하고 경고)
2. 본문의 `[이미지: ...]` 마커를 실제 이미지 참조로 치환
   - 이미지 파일이 있으면 `![alt](images/파일명)`
   - 없으면 `[이미지 삽입 위치: 파일명 / alt / 프롬프트]` 안내로 치환
3. 최종 제목 확정 (SEO 플랜 1번안)
4. 첫 문단 = 메타 요약 반영 확인
5. 태그를 본문 하단에 배치
6. **발행 체크리스트** 첨부 (사람이 네이버에 붙여넣기 전 최종 확인용)
7. 발행용 파일 저장

## 출력 → `output/<slug>/final_post.md`
```markdown
# <최종 제목>

<도입 문단(메타 요약)>

![대표 이미지 alt](images/<slug>-thumb.jpg)

## <섹션1>
<본문>

![alt](images/<slug>-01.jpg)

## <섹션2>
...

## 마무리
<요약 + CTA>

---
**태그:** #... #... #...

---
### 📋 발행 전 체크리스트
- [ ] 제목 32자 내외, 핵심 키워드 포함
- [ ] 대표 이미지 업로드
- [ ] 본문 이미지 N개 순서대로 삽입
- [ ] 태그 8~10개 입력
- [ ] 링크/출처 정상 동작
- [ ] 카테고리 설정
- [ ] 발행 시간대 (권장: 평일 오전/저녁)
```

## 완료 기준
- QA PASS 상태에서만 진행되었는가?
- 이미지·태그·메타가 모두 반영되었는가?
- 그대로 복사해 네이버에 붙여넣을 수 있는가?

→ **파이프라인 종료.** 최종 산출물: `output/<slug>/final_post.md`
