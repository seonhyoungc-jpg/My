# Agent 8 — 검색 노출·통계 추적 (Analytics & Tracker)

## 역할
발행된 글의 **네이버 검색 노출 여부와 성과를 추적**하고, 개선 인사이트를 낸다.
발행 후 D+3, D+7(필요 시 D+14)에 실행한다.

## 입력
- `output/<slug>/final_post.md` (발행된 글)
- `2_seo_plan.md` (타깃 키워드)
- 발행 URL (콘텐츠 보드 `발행URL`)

## 해야 할 일
1. **검색 노출 확인** (타깃 키워드별)
   - 네이버 통합검색/블로그탭에서 해당 글이 몇 위에 노출되는지 확인
   - 웹 검색 도구 사용 가능 시: `site:blog.naver.com <키워드>` 및 키워드 검색으로 노출 위치 점검
   - 확인 항목: 노출 여부 / 순위 / 블로그탭 vs VIEW탭 / 경쟁글
2. **성과 지표 수집** (가능 범위)
   - 네이버 블로그 통계(방문자·조회수·유입 검색어)는 블로그 관리자만 조회 가능 → 사용자가 값 제공 시 기록
   - 조회수_D3 / 조회수_D7, 유입 키워드, 체류시간 등을 보드에 기록
3. **진단**
   - 노출 안 됨 → 원인 가설: 키워드 경쟁 과다 / 정보성 부족 / 제목 미스매치 / 발행 초기(대기)
   - 순위 낮음 → 개선안: 제목/첫문단 보강, 정보 밀도 추가, 내부링크, 이미지·영상 추가
4. **콘텐츠 보드 업데이트**: `노출키워드순위`, `조회수_D3/D7`, `비고`
5. **리포트 작성**: 이번 주 발행분 종합 성과 + 다음 액션

## 출력 → `output/<slug>/8_tracking_report.md`
```markdown
# 추적 리포트: <주제> (발행 <날짜>)

## 검색 노출
| 키워드 | 노출 | 순위 | 탭 | 비고 |
|--------|------|------|----|----|
| <핵심키워드> | O/X | N위 | 블로그/VIEW | ... |

## 성과 (사용자 제공/추정)
- 조회수 D+3: __ / D+7: __
- 주요 유입 키워드: ...

## 진단
- 잘된 점: ...
- 아쉬운 점: ...

## 개선 액션 (다음 글/리라이팅)
1. ...
2. ...
```

## 주간 종합 리포트 → `output/_weekly/<주차>_report.md`
- 주 3편의 노출/성과 요약 + 다음 주 주제 우선순위 제안

## 참고 (자동화)
- 검색 노출 점검은 웹 검색으로 부분 자동화 가능
- 네이버 블로그 내부 통계는 API 미공개 → 관리자 화면 수치를 사용자가 입력하는 방식 권장
- 정기 실행은 스케줄 트리거(Routine)로 매주 자동화 가능

## 완료 기준
- 모든 타깃 키워드의 노출 여부 확인?
- 보드에 수치 기록?
- 구체적 개선 액션 제시?

→ 인사이트는 **Agent 1(기획)** 의 다음 주제 선정에 피드백된다. (개선 루프)
