# 개요: 양고기 누린내 안 나게 고르는 법

## 검색 의도
**문제해결형** — "양고기 먹고 싶은데 냄새가 걱정된다"를 해결하고 싶은 사람.
단순 조리법이 아니라 **왜 냄새가 나는지 + 어떻게 피하는지**를 원함. 구매 직전 단계.

## 타깃 페르소나
양고기를 식당에서 몇 번 먹어봤거나, 아예 처음인 20~40대.
"집에서 구워보고 싶은데 실패하면 비싼 고기 버리는 것"이 가장 큰 두려움.
→ 확신을 주면 바로 구매로 이어지는 층.

## 키워드
- **핵심**: 양고기 누린내
- **연관**: 양고기 냄새, 양고기 손질, 호주산 램, 양고기 부위
- **롱테일**: 양고기 처음, 양고기 지방 제거, 냉동 양고기 해동, 양고기 입문

### 공통점
- 국내 자료는 **조리 단계 처방 위주** — 식초물 담그기, 우유 담그기, 올리브유 코팅, 향신료
- **원인 설명 없이 방법만** 나열하는 구조가 대부분
- 레시피 사이트 중심이라 **"어떻게 고를까"(구매 단계) 관점이 약함**

### 적용할 점
- 식초·우유 담그기는 실제로 널리 쓰이는 방법 → 언급은 하되 **순서상 뒤**에 둔다
- 담그는 시간이 길면 육즙이 빠진다는 주의사항이 실제로 지적됨 → 반영

### 차별화할 점 ⭐
1. **원인부터 설명** — 국내 자료 대부분이 빠뜨린 지점
2. **구매·선택 관점** — 레시피 사이트와 다른 각도 (유통사의 강점)
3. **램/머튼 연령 구분** — 확인한 국내 자료 중 이를 명시한 건 3번 기사 정도
4. **부위별 지방 분포** — 확인한 자료에 없음

### 확인된 사실 (중요)
- ✅ **사장님 말씀이 과학적으로 뒷받침됨**: 누린내의 주원인은 지방에 축적되는 **분지쇄 지방산(BCFA)** — 4-메틸옥탄산, 4-에틸옥탄산 등
- ✅ **지방량이 많을수록 향이 강해짐** — America's Test Kitchen 실험으로 확인
- ✅ **나이가 들수록 해당 성분 농도 증가** → 램/머튼 차이의 근거
- ✅ **사료(풀 vs 곡물)도 향에 영향** — 새로 확인된 사실, 본문에 추가 가능
- ⚠️ **램 연령 기준은 출처마다 다름** (12개월 / 14개월) → 본문에서 단정하지 말 것

### 확인 불가
- 각 경쟁글의 **검색 순위·조회수** — 확인 수단 없음. **추정하지 않음**
- "양고기 누린내" 키워드의 **검색량·경쟁도** — 확인 불가
- 다만 한국어 심층 자료가 적고 레시피 사이트 위주라는 점은 검색 결과로 관찰됨 (순위 근거는 아님)

## 차별화 포인트 ⭐
- **"누린내는 살이 아니라 지방에서 난다"는 원인부터 짚는다** — 유통 현장의 지식
  → 원인을 알면 대응이 달라진다는 구조로 글 전체를 설계
- **램과 머튼 연령 구분**을 명확히 설명 (경쟁글이 빠뜨린 지점)
- **부위별 지방 분포**로 입문자 추천 부위를 제시
- **냉장/냉동 해동 차이**가 냄새 체감에 영향을 준다는 실무 포인트

## 목차
1. 도입 — 누린내로 양고기 포기한 분들 / 결론 선제시(지방)
2. 누린내는 어디서 나는가 — 지방이 원인
3. 램과 머튼 — 연령이 먼저다
4. 부위별 지방 분포와 입문용 추천
5. 겉지방 정리하는 법
6. 냉장과 냉동, 해동이 냄새를 가른다
7. 그래도 향이 신경 쓰이면 — 허브·불 조절
8. 마무리 — 요약 + CTA
