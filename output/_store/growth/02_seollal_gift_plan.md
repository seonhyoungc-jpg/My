# 2027 설 선물세트 기획안 — 고메365

> 작성일: 2026-11-14 · 설 당일: **2027년 2월 6일(토)**
> 원가·배송비 자료를 아직 받지 못해 **판매가는 "목표 가격대"**로만 제시함. 원가를 받으면 최종 가격과 이익을 확정.

---

## 1. 기획 방향 한 줄
**"검은 상자에 담긴, 받는 사람이 고기 맛으로 기억하는 선물"**
- 비싼 한우 대신 **수입 프리미엄 고기를 합리적인 가격**으로 → 고메365 브랜드 방향 그대로
- 다른 데서 흔치 않은 **양갈비 선물세트**가 차별점 (이미 리뷰로 맛 검증: 맛있어요 94%)

## 2. 라인업 (5종)

| 등급 | 세트 이름(가제) | 구성 (공급처 확인 필요) | 목표 판매가 | 역할 |
|---|---|---|---|---|
| 실속 | **명절 찜갈비 세트** | 소갈비 찜용 + 특제 간장소스 | 6~7만 원대 | 신규 손님 유입, 가족 명절 상차림용 |
| 대표 ① | **프렌치랙 선물세트** | 커팅 프렌치랙 + 쯔란·소스 | 8~9만 원대 | 고메365만의 차별 상품 (현재 베스트 1위) |
| 대표 ② | **갈비 패밀리 세트** | 찜갈비 + LA갈비(공급 가능 시) | 10~12만 원대 | 설에 가장 많이 찾는 구성 |
| 프리미엄 | **스테이크 세트** | 토마호크 + 프렌치랙 + 등심·채끝류 | **15만 원 이하** | 기업·거래처 선물 (아래 3번 참고) |
| 최상위 | **고메365 시그니처** | 통 프렌치랙 + 숄더랙 + 토마호크 | 20~25만 원대 | 브랜드 이미지, 객단가 견인 |

- 기존 "양고기 선물세트 숄더랙(106,000원)"은 **대표 ② 가격대에 맞춰 시그니처로 개편하거나 단종**
- 돼지고기는 선물 수요가 작은 편이라 이번 설엔 **제외 권장**. 공급처에 프리미엄 돼지 구성이 있으면 실속 등급에 추가 검토
- ⚠️ **원산지를 세트명·썸네일·상세에 분명히** 표기 (예: "호주산"). "한우"가 아닌 고기에 한우 연상 표현을 쓰면 원산지 위반이 될 수 있어요

## 3. 기업·거래처 선물 수요 (B2B의 첫걸음)
- 청탁금지법상 공직자 등에게 주는 농축수산물 선물 한도는 **15만 원, 설·추석 기간엔 30만 원**이에요 (2024년 8월 개정 기준)
- 그래서 기업 담당자들은 **5만·10만·15만 원 구간**을 많이 찾아요 → 프리미엄 세트를 15만 원 이하로 맞추는 이유
- 준비할 것: **대량 구매 할인표**(10/30/50세트), 견적서 양식, 세금계산서 발행, **여러 주소 한 번에 접수용 엑셀 양식**
- 이 고객 리스트가 나중에 **B2B 육류 납품 사업**의 출발점이 돼요

## 5. 가격 정하는 공식 (원가 받으면 바로 계산)
```
세트 1개당 남는 돈 = 판매가 − 공급가 − 포장비 − 배송비 − 네이버 수수료 − 광고비(1개당)

공급가 상한 = 판매가 × (1 − 수수료율 − 광고비율 − 목표이익률) − 포장비 − 배송비
```

|---|---|---|---|---|---|---|---|

| 프렌치랙 | | | | | | | |
| 갈비 패밀리 | | | | | | | |
| 스테이크 | | | | | | | |
| 시그니처 | | | | | | | |
> 빈칸은 공급처 자료 + 정산 내역(실제 수수료율)으로 채워요. 지어낸 숫자는 넣지 않았어요.

## 7. 상세페이지 구성 (블랙 톤)
1. **첫 화면**: 검은 배경 + 열린 블랙 박스 속 고기 실사 + 세트명·가격 한 줄
2. **왜 고메365인가**: 리뷰 1,380개 · 평점 4.9 · 맛있어요 94% · 원산지 · 냉동/냉장 상태
3. **세트 비교표**: 5종 구성·중량·인분·가격 한눈에
4. **포장 실물 사진**: 박스, 보냉가방, 메시지 카드 (선물은 포장을 보고 사요)
5. **배송 일정표**: 주문 마감일, 도착 예정, 받는 날짜 지정 방법
6. **받는 분을 위한 안내**: 보관법·해동법·굽는 법 (QR로 블로그 글 연결)
7. **실제 리뷰**
8. **자주 묻는 질문**: 메시지 카드, 대량 주문, 영수증·세금계산서, 지연 시 처리

디자인 원칙: 블랙·차콜 배경, 브라운 포인트, 글자는 적게, 할인 문구는 작게, 사진은 크게.
